## Pono Data Solutions

Software and data tools, built in the United States.

### What we work on

- **Pono OS** - a chat-first assistant for iPhone, with a desktop build.
- **Pono Print** - firmware, a slicing pipeline, and an on-device touch UI for a 3D printer.
- **Run Scenario** - an AI roleplay engine, live at [run-scenario.com](https://run-scenario.com).
- **Pono Toolkit** - a Windows utility for Lenovo Legion laptops. Open source.

Most of our work is private. The public repositories here are the open-source pieces.

More at [ponodata.com](https://ponodata.com).
